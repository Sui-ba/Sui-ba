## 🎧 Трек 01 · Интро

Привет! Я **Swifty** (он же **Sui**). Делаю приложения, которые решают реальные задачи:
от мобильного финансового учёта до сайтов для живого бизнеса и инструментов автоматизации.

- 📱 Сейчас собираю **FinPro** — финансы с глубокой аналитикой на Flutter, работает даже без интернета
- 🤖 Автоматизирую рутину на **Python**: веб-интерфейсы, Telegram-боты, SQLite
- 🌐 Делаю сайты, которые продают: **RyzenHub** и редизайн **«Неба Томска»**
- 💡 Девиз: *«Баг — это пауза, а не точка»*
